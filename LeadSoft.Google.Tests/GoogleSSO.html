Gerador de Token Google SSO

Utilitário para obter o id_token e o access_token do Google OAuth 2.0 e usá-los como TestIdToken e TestAccessToken na GoogleSSOFixture.

Encontrado em Google Cloud Console → Credenciais → OAuth 2.0 Client IDs. Equivale à env var GOOGLE_SSO_CLIENT_ID.
URI exata cadastrada no Google Cloud Console para este Client ID. Deve ser servida via http:// ou https:// — não funciona com file://. Use npx serve . para servir esta pasta localmente.
Restringe o login a contas de um domínio GSuite específico (equivale à env var GOOGLE_SSO_HOSTED_DOMAIN). Deixe em branco para aceitar qualquer conta Google.

Escopos solicitados

openid email profile user.birthday.read user.phonenumbers.read
Os escopos em cinza (birthday, phonenumbers) são necessários para testar GetUserProfileAsync com campos expandidos. Podem exigir verificação do app para contas externas ao seu projeto Google Cloud.

Tokens obtidos

Cole estes valores nos campos correspondentes de GoogleSSOFixture.cs para habilitar os testes de integração.

ID Token  TestIdToken
Use em GetOAuthSSOAsync(TestIdToken).
Payload decodificado
Access Token  TestAccessToken
Use em GetUserProfileAsync(TestAccessToken).
⚠ Atenção: Não faça commit destes tokens — são credenciais de acesso temporárias. Preencha-os apenas localmente na fixture e remova antes de qualquer push.
